# 空海地一体化 AI 指挥中枢 (AI Command Center)

本系统是一个基于大语言模型（LLM）驱动的战术决策与指挥调度原型。它实现了从自然语言指令解析、态势数据过滤到战术方案生成的全链路自动化。

## 🚀 系统架构

系统采用 **意图解析 -> 数据过滤 -> 战术生成** 的三步走逻辑：

1.  **意图解析 (Intent Parser)**: 使用 `qwen-turbo` 模型将模糊的自然语言指令拆解为结构化任务（JSON AST）。
2.  **数据中枢 (Data Processor)**: 模拟“物理隔离”环境。根据 `database.json` 校验目标合法性、兵力状态及航线匹配，执行硬性拦截。
3.  **参谋引擎 (Staff Officer)**: 基于校验后的事实数据，自动生成符合军事逻辑的 Markdown 作战方案及 JSON 格式的底层控制指令。

## 📂 项目结构

- `main.py`: **系统启动主程序**。包含 7 条极限压力测试用例，覆盖侦察、打击、封控及非法指令拦截场景。
- `intent_model.py`: 意图识别模块，负责理解长官意图并转换为机器指令。
- `staff_officer.py`: 战术参谋模块，负责编写详细的作战文书和下发控制 ID。
- `data_processor_v2.py`: 态势过滤引擎，负责兵力匹配、航线选择及安全熔断。
- `database.json`: 虚拟态势数据库，包含区域情报、待命装备及其协议/能力。
- `prompts/`: 核心逻辑存放处，包含意图解析和方案生成的系统级 Prompt。
- `output_plans/`: 自动生成的作战方案（Markdown）和控制数据（JSON）存放目录。

## 🛠️ 环境准备

1.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```

2.  **配置 API Key**:
    项目使用阿里云百炼 API。如需更换 API Key，请同步修改 `intent_model.py`、`staff_officer.py` 和 `test.py` 中的 `MY_API_KEY` 变量。

## 🧪 测试流程

### 第一步：连通性测试
验证 API Key 是否有效以及网络连接是否通畅：
```bash
python test.py
```

### 第二步：全链路系统演练
启动主程序执行预设的战术测试集：
```bash
python main.py
```
**观察重点**:
- **意图拆解**: 查看系统如何将“复合指令”拆解为多个子任务。
- **数据拦截**: 观察对于“轰炸非法坐标”或“在内陆部署潜艇”等逻辑错误的拦截机制。
- **方案生成**: 系统成功生成方案后，会播报语音（文本形式）并展示生成的控制 ID。

### 第三步：查看战术产物
测试运行后，检查 `./output_plans/` 目录：
- `Plan_... .md`: 详细的战术方案文书。
- `ControlData_... .json`: 结构化的装备控制参数。
